# Jurassic Domination — creature visual-reference catalog

Source: `src/data.js` plus `src/content.js` from the public GitHub repository (checked Nov 16, 2026). The source roster has **102 distinct IDs**: **62 dinosaurs**, **8 other prehistoric animals**, **1 fictional prehistoric hunter**, **24 fantasy creatures**, and **7 bloodline variants**.

**Reference labels:** “Direct image” opens a specific checked reconstruction. “Reference image gallery” opens an image-search gallery for the exact species, because no single individual illustration was confirmed. Never assume a gallery image or source is licensed for redistribution; use only for anatomy/design inspiration unless licensing permits re-use. For hybrids and fantasy creatures, the references are anatomical inspirations, not scientifically grounded reconstructions.

Taxonomy notes: *Dimetrodon* is a synapsid; *Sarcosuchus*/*Deinosuchus* are crocodyliforms; *Quetzalcoatlus*/*Hatzegopteryx* are pterosaurs; *Titanoboa* is a snake; *Plesiosaurus* and *Kronosaurus* are marine reptiles, not dinosaurs. *Troodon* and *Stygimoloch* have taxonomic uncertainties.
